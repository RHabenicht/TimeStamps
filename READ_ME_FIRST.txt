TimeStamps 2.5 — Updated by NightLife

Install or upgrade with TimeStamps_2.5_Setup_Updated_by_NightLife.exe. The per-user installer creates Start Menu shortcuts and an uninstaller. It preserves existing settings and unrelated user files during an upgrade.

At startup, the full approved splash artwork appears for six seconds before the main window. The PNG includes its serpent logo; the app does not draw a second icon over it.

If the splash fails, check:
%APPDATA%\TimeStamps\splash_errors.log
