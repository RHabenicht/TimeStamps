TimeStamps 2.3 — Regression report (November 6, 2026)

REPORTED ISSUE
The Format page locks up in TimeStamps 2.2 on the user's Windows monitor.
Cause not independently reproduced; Win32 nested control notification path
identified as a plausible contributor from static review.

CHANGES
- The nav buttons now schedule page changes via WM_APP_SWITCHPAGE/PostMessageW.
- Win32 command events cannot reenter page visibility updates.
- Preset selection now schedules its edits through WM_APP_APPLYPRESET.
- UI no longer modifies navigation button captions while switching pages.
- The output font remains fixed at 16-point Consolas.
