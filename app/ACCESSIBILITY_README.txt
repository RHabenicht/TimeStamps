TIMESTAMPS 2.3 — ACCESSIBLE WINDOWS PREVIEW
Updated by NightLife
==========================================

TARGET DISPLAY
1360 x 768 screen resolution, 125% Windows display scaling, HDMI monitor.
The window now opens within the usable desktop/work area (excluding the taskbar).
The fixed 790-pixel-tall starting window and 760 DPI-independent minimum height
from the earlier preview have been removed.

HOW TO USE
1. Extract the complete ZIP archive to a folder.
2. Run TimeStamps.exe. No installer or administrator access is required.
3. Use SETUP for the date, number of timestamps, spacing and posting hours.
4. Use FORMAT for timestamp templates, date styles, and time styles.
5. Click Generate timestamps at the bottom of either page.
6. The app switches to RESULTS. Use Copy selected, Copy all, Save .txt or Clear.
7. RESULTS uses a fixed 16-point Consolas font to avoid a crash reported with A+/A− controls.
8. Use the top tabs to return to Setup or Format.

ACCESSIBILITY IMPROVEMENTS
- 13-point default Segoe UI interface text.
- Fixed 16-point Consolas output text; unstable A+/A− controls removed.
- 38–43 DPI-independent-unit button and input heights.
- Tabbed layout instead of a single fixed-height form.
- DPI-aware layout intended for Windows scaling at 125%.
- Persistent Generate button and bottom status bar.
- App opens centered within the available Windows work area.
- User's existing settings, legacy INI migration and all core engine features
  are preserved.

IMPORTANT TEST LIMITATION
The timestamp engine, format presets, navigation message flow and new layout geometry have been tested as far as possible outside Windows. The 64-bit
Windows GUI executable compiles. It has NOT been executed in a Windows 10/11
session here, so final visual fit at the exact monitor must be verified locally.
The window can be resized or maximized. If anything is cut off, report the
screen's exact text-size setting and the affected tab.

INSTALLER
No installer is included in this revision. Installer packaging remains on
hold until the GUI is confirmed satisfactory.
