TimeStamps 2.5 — Updated by NightLife

Use the Windows installer TimeStamps_2.5_Setup_Updated_by_NightLife.exe to install or upgrade.
The installer creates shortcuts and an uninstaller under Windows Settings > Installed apps.
Existing settings are retained. A new version installs over the prior per-user installation.
The 4-second splash is displayed at startup. The application icon is now embedded into both executables.
If the splash cannot start, see AppData/Roaming/TimeStamps/splash_errors.log for diagnostics.
The original programming credits remain in ORIGINAL_CREDITS.txt.
