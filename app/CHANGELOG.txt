TimeStamps 2.0 — Updated by NightLife
Date: 2026-11-06

- Reconstructed the original Delphi 3 Windows 95-era program as a native,
  portable 64-bit Windows 10/11 desktop application.
- Redesigned the interface using Segoe UI fonts, a dark header, light
  settings/output panels, and a custom window icon.
- Preserved randomized sequential timestamp generation.
- Fixed overnight-hours calculation so times obey allowed posting windows.
- Added explicit validation for time gaps and quantity.
- Added format presets and editable token templates for date/time strings.
- Added Copy selected, Copy all, and Save .txt actions.
- Added safe overwrite/clear/exit confirmations for unsaved output.
- Saves settings under the current user's Windows profile, not beside the EXE.
- Migrates the original TimeStamps.ini format without changing that file.
- Added persistent continuation between sessions and ability to start fresh
  by changing the start date.
- Preserved original 1997 programmer and requirements credits.
- Added automated tests for all 576 hour-window combinations.

Known remaining verification:

  Windows 10/11. Windows UI/runtime testing is still required.
- Native controls use the Windows desktop theme; on-screen appearance may
  differ with system scaling and Windows version.
